A modern, responsive and feature-rich calculator built using **HTML, CSS and JavaScript**.

It supports basic calculations, scientific operations, memory functions, calculation history, dark mode and useful smart tools like BMI, EMI, Age and Unit Converter.

## ✨ Features

- ➕ Basic arithmetic operations
- 🔬 Scientific calculator
- 📊 Percentage calculation
- √ Square root
- x² Square
- xʸ Power calculation
- sin, cos, tan
- log and ln
- π and e constants
- Factorial
- 1/x reciprocal
- 🧠 Memory functions
  - MC
  - MR
  - M+
  - M-
- 📜 Calculation history
- 💾 History saved using LocalStorage
- 🌙 Dark mode
- ⌨️ Keyboard support
- 📱 Responsive design
- 🧮 BMI Calculator
- 💰 EMI Calculator
- 🎂 Age Calculator
- 📏 Length Unit Converter

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
